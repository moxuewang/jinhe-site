# 锦盒官网

官网：<https://moxuewang.github.io/jinhe-site/>

这是锦盒的独立静态官网，介绍已发布功能，提供工具目录和官方下载入口。HTML、CSS、JavaScript 及网站图片均不需要构建工具或第三方运行服务。

- Android 安装包：[jinhe-releases](https://github.com/moxuewang/jinhe-releases/releases/latest)
- 按类别单独下载官方插件：[jinhe-plugins](https://github.com/moxuewang/jinhe-plugins)

此仓库仅含官网文件，应用本体源码不公开。工具目录标注其对应的应用版本；未发布的改动不作为已上线能力宣传。

GitHub Pages 从 `main` 分支根目录发布。修改后提交即可更新；`.nojekyll` 表示直接提供静态文件。
